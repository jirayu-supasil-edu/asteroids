# Asteroids

This project involves building a simple video game based on the classic [Asteroids](<https://en.wikipedia.org/wiki/Asteroids_(video_game)>). If you've never played it before, you can take a look at this [version of the game](https://www.echalk.co.uk/amusements/Games/asteroidsClassic/ateroids.html), which is slightly different from ours.

## Prerequisite

- Python 3.10+ installed (see the Bookbot project for help if you don't already have this)
- The uv project/package manager
- Access to a Unix-like shell (e.g., zsh or bash)
